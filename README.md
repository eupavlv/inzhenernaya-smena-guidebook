# Инженерная смена — гайдбук фирменного стиля

Черновик гайдбука конструкторского бюро «Инженерная смена» (Мончегорск).
Заказчик — Мончегорский политех и ФабЛаб Мончегорск. Проект рассчитан на 2026–2028.

Страница собрана как один самодостаточный HTML-файл: шрифт лежит рядом, иконки вшиты
в разметку, внешних зависимостей нет.

## Что внутри

Собранные разделы: о проекте, цвет, шрифты, композиция, фирменная графика, иконки.
Разделы логотипа, key visual, соцсетей, презентации и документации ещё в работе — в навигации
они помечены серым.

## Лицензии на используемое

- Шрифт **Geologica** — SIL Open Font License 1.1, текст лицензии в `fonts/OFL-Geologica.txt`
- Иконки **Phosphor** (вес Thin) — MIT, https://github.com/phosphor-icons/core
- Шрифт **Arial** упоминается как системный, файлы не распространяются

Фотографии в примерах визуала сгенерированы нейросетью, реальные люди на них не изображены.
